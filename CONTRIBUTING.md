# Contributing

This is a small, opinionated set of documents and one enforcement script, published as-is. There's
no roadmap and no support commitment attached to it.

If something is wrong, incomplete, or you've adapted a piece of it usefully — a pull request with a
short description of what changed and why is welcome. Please keep additions in the same spirit:
small, generic (no project-specific assumptions baked in), and honest about what's proven versus
aspirational.

Things this repo will not take on:
- Framework- or language-specific tooling. The templates and hooks here are intentionally
  agent-agnostic and stack-agnostic.
- A general-purpose agent orchestration system. That's a much bigger scope than this repo covers.
